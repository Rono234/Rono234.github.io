Project Overview

Hazoorah is a logic-based puzzle game where players solve visual deduction riddles by arranging characters and items on a grid according to a set of logical rules. Each level presents clues such as positional constraints and relationships between objects, challenging players to think critically and experiment with different arrangements.

As players progress through levels and themed towns, puzzles increase in complexity by introducing more elements, stricter rules, and larger grids. The game rewards observation, reasoning, and persistence.

Key Features

  • Visual, logic-based deduction puzzles
  • Drag-and-drop interactive grid system
  • Multi-level progression across themed towns
  • Hint system with limited usage per level
  • Star-based scoring and attempt limits
  • Pause, resume, shuffle, and reset controls

Core Systems & Gameplay Logic

  • Puzzle Logic System: Validates user arrangements against correct solutions and generates contextual hints.
  • Level Progression System: Manages level unlocking, star ratings, and town-based advancement.
  • User Grid Gameplay: Provides a tactile drag-and-drop grid for testing logical deductions in real time.
  • Game State Management: Tracks progress, saves sessions, and ensures smooth transitions between screens.

Design & User Experience

Hazoorah emphasizes an intuitive and playful interface, using original illustrations, colorful themes, and clear visual feedback to guide players through complex logical problems. The design supports both desktop and mobile layouts, ensuring accessibility and ease of play.

Why Hazoorah?

This project explores how abstract logical reasoning can be transformed into an engaging, visual game experience. Hazoorah was designed to strengthen critical thinking skills while remaining approachable, creative, and fun.
